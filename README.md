# 수문·수자원 논문 브리핑

Windows에서 최근 수문·수공·수자원 분야 논문을 정리하고 노션 표 데이터베이스에 누적하는 프로그램입니다.

- [실행 방법과 설정 안내](hydro-paper-digest/README.md)
- [Windows EXE 빌드 및 다운로드](../../actions/workflows/build-hydro-windows.yml)

소스 실행: Code → Download ZIP → 압축 해제 → hydro-paper-digest/start.bat (Python 3.10 이상 필요).

Windows EXE는 Actions의 성공한 빌드 → Artifacts → HydroPaperDigest-Windows에서 다운로드합니다. API 키는 프로그램에 직접 입력하며 저장소에 업로드하지 마세요.
