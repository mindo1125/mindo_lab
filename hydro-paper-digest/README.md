# 수문·수자원 논문 브리핑 (Windows)

매일 한국시간 00:00에 최근 수문학·수공학·수자원공학 논문을 해외(영어) 1편, 한국어 1편씩 골라 한국어로 정리하고 파일과 노션 표 데이터베이스에 누적하는 데스크톱 앱입니다.

## 가장 쉽게 실행: Windows EXE

1. GitHub 저장소의 **Actions** 탭을 엽니다.
2. **Build HydroPaperDigest for Windows**의 가장 최근 성공한 실행을 엽니다.
3. 아래 **Artifacts → HydroPaperDigest-Windows**를 다운로드합니다. GitHub 로그인이 필요합니다.
4. 압축을 풀고 **HydroPaperDigest.exe**를 실행합니다. Python 별도 설치가 필요 없습니다.

빌드는 업로드 이후 GitHub Actions에서 수행됩니다. 녹색 성공 표시가 뜨기 전에는 EXE가 준비된 것이 아닙니다. 저장소 정책 때문에 자동 실행이 안 되면 Actions 탭에서 워크플로를 허용한 후 Run workflow를 누르세요. 개인 인증서로 서명하지 않은 앱이라 Windows가 출처 확인을 요청할 수 있습니다. Artifacts는 30일 보관하며 만료 시 Run workflow로 다시 빌드합니다.

## 소스 코드로 바로 실행

GitHub **Code → Download ZIP** → 압축 풀기 → `hydro-paper-digest` 폴더 → **start.bat** 더블클릭. Python 3.10 이상이 필요하며 없으면 공식 설치 페이지가 열립니다. 추가 라이브러리는 필요 없습니다. Mac/Linux에서는 `python3 app.py`를 실행합니다(Tkinter가 설치되어 있어야 합니다).

## 처음 설정

1. [OpenAlex](https://openalex.org/settings/api) API 키를 발급받아 입력합니다.
2. [OpenAI](https://platform.openai.com/api-keys) API 키를 발급받아 입력합니다. ChatGPT 구독과 API 과금은 별개이며 제공자의 현재 요금·이용 한도를 확인하세요.
3. **설정 저장 → 지금 수집**을 누릅니다. 노션이 없어도 파일 저장은 됩니다.
4. **자정 자동 수집**을 체크하고 설정을 저장하면, 이 창이 실행 중일 때 한국시간 날짜 변경을 10초 간격으로 감지합니다. 결과 생성에는 검색·요약 시간이 더 걸립니다.

자동 수집을 켜면 실행 직후 오늘분을 보완하고 이후 15분마다 누락 논문과 노션 전송을 재시도합니다. 같은 날짜의 이미 선정한 논문은 교체하지 않습니다. 과거 미실행 일자를 소급 생성하지 않습니다. PC 종료·절전 중에는 동작하지 않습니다. 이 앱은 OS 작업 스케줄러나 시작 프로그램에 자동 등록하지 않습니다.

## Notion 표 연결

1. [Notion 내부 통합](https://www.notion.so/profile/integrations)을 만들고 콘텐츠 읽기·삽입 권한을 부여합니다.
2. 누적할 빈 **상위 페이지**를 하나 만들고 페이지의 연결 메뉴에서 통합을 추가합니다.
3. 앱에 통합 토큰과 그 상위 페이지의 URL 또는 ID를 입력합니다. 기존 데이터베이스 URL이 아니라 상위 페이지 주소를 입력하세요.
4. 수집 버튼을 누르면 상위 페이지 아래에 **수문·수자원 논문 브리핑** 인라인 데이터베이스가 생성됩니다.

열: 제목, 저자, 연구 동기, 3줄 요약, 구분, 수집일, 발행일, 학술지, 인용 수, 선정 점수, PDF, DOI, 논문 ID, 정리 범위. 자동 생성한 데이터베이스 이름과 열 이름·유형을 유지하세요. PDF는 링크로 노션에 추가하고 파일 자체는 PC에 저장합니다.

노션 실패 시 로컬 결과를 보존하고 다음 실행에서 미전송분을 재시도합니다. 논문 ID 열을 조회해서 응답 유실 후 중복 생성도 줄입니다. 같은 PC의 동시 수집은 OS 파일 잠금으로 방지합니다. 여러 PC에서 같은 노션 데이터베이스를 동시에 운영하는 것은 지원하지 않습니다. Notion API 2022-06-28 호환 버전을 사용합니다.

## 선정 기준과 한계

- 최근 365일(30~1825일로 변경 가능)의 학술지 article, OpenAlex 철회 표시 없음, 공개 PDF 링크와 초록이 있는 논문.
- 홍수·가뭄·기후변화 시나리오·AI 예측·하천 분야의 검색어를 언어별 5개 사용하고 각 검색 결과 상위 50개를 합칩니다. 관련 키워드 필터를 추가하며 전수검색은 아닙니다.
- 해외는 **영어 논문** 기준입니다. 한국 기관의 영어 논문이 포함될 수 있으며 저자 국적이나 발행국을 판별하지 않습니다.
- 점수 = log(1 + 인용 수 × 365 / max(발행 후 일수, 30)) + 0.15 × min(관련 키워드 수, 8). 동점은 최신 발행일 우선.
- 이 점수는 주목도의 대리지표입니다. **조회수·SNS 언급량·최근 인용 증가량을 측정하지 않습니다.** 공급원의 인용 누락과 지연이 있습니다.
- **한국어 논문은 OpenAlex 수록량이 적어 매일 1편을 보장하지 못합니다.** 부족 상태를 기록하고 다른 언어는 계속 처리합니다. 추후 KCI/ScienceON 공식 API 연결로 보강할 수 있습니다.
- 연구 동기와 3줄 요약은 **초록만 근거로** 생성합니다. 전문을 읽은 분석이 아니며 AI 결과는 검토가 필요합니다. 초록에 없는 동기는 추정하지 않습니다.
- 중복은 DOI를 우선하고 없으면 OpenAlex ID를 사용합니다. 공급원 메타데이터가 잘못되면 중복 판별에 한계가 있습니다.
- 공개 PDF만 최대 25MB까지 저장합니다. 실패 시 공급원이 등록한 직접 PDF 링크를 유지하나 링크 유효성은 보장하지 않습니다. 유료 접근 장벽을 우회하지 않습니다.

## 저장 위치와 개인정보

Windows: `%LOCALAPPDATA%\HydroPaperDigest` (앱의 **저장 폴더 열기** 버튼).

- `YYYY-MM-DD/en.md`, `ko.md`: 정리 문서
- `YYYY-MM-DD/en.json`, `ko.json`: 초록 포함 메타데이터
- 같은 폴더에 다운로드한 PDF
- `history.sqlite3`: 전체 이력과 노션 전송 상태
- `config.json`: 설정과 **평문 API 키**. 공유·Git 업로드 금지

프로그램은 개인 PC용입니다. 사용자의 Windows 계정 파일 접근 권한으로 보호되며 비밀키를 암호화해 보관하지 않습니다. 데이터 폴더 전체를 안전하게 백업하세요. 외부 전송: OpenAlex(검색어), OpenAI(제목·초록), Notion(연결 시 정리 내용), 원문 제공자(PDF 요청).

## 개발·검증

```
python -m unittest discover -s tests -v
python app.py
python app.py --once
```

자동 테스트는 모의 API를 사용합니다. 사용자 키를 받지 않아 실제 OpenAlex/OpenAI/Notion 연결은 검증하지 않았습니다. Windows EXE 실행 검증은 별도 Windows PC에서 필요합니다. GitHub Actions는 Windows에서 테스트와 EXE 빌드를 수행하지만 앱 화면의 실제 사용까지 검사하지 않습니다.

### GitHub Actions를 쓸 수 없는 경우

Windows에 Python을 설치한 뒤 `build_exe.bat`을 더블클릭하면 테스트 후 `dist/HydroPaperDigest.exe`를 만듭니다. 첫 빌드에는 인터넷 연결이 필요합니다. 완성된 EXE는 Python 설치 없이 실행할 수 있습니다.
